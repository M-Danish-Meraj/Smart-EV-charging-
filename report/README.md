# report/

| Path | What | Source |
| --- | --- | --- |
| `CT363_Smart_EV_Report.docx` | **Final report**, editable Word file (title page, all CEP sections, pseudocode, proofs, complexity, results, references, appendices) | generated by `scripts/build_report.py` |
| `CT363_Smart_EV_Report.pdf` | The same report as PDF | generated (printed from the `.html` with Edge/Chrome) |
| `CT363_Smart_EV_Report.html` | The same report as a web page (the PDF source) | generated |
| `SUBMISSION_CHECKLIST.md` | CEP checklist with status, and what the team must still do by hand | written |
| `project_explained.html` | Plain-language explainer of the whole project | written |
| `methods_notes.md` | Pseudocode, proofs, complexity, mapping and trade-off tables (no measured numbers) | written to match `src/` |
| `figures/*.png` | Network maps (E1, E2, E3), benefit by scenario, E5 scaling charts, architecture diagram | generated |
| `generated/results_summary.md` | Every table from E1–E5 plus verification | generated |
| `generated/edge_cases.log` | The three CEP-mandatory edge cases with actual output | generated |

To regenerate everything:

```
python run_all.py
python scripts/build_report_assets.py
python scripts/build_report.py
```

The report builder reads every number from `output/results.json`; nothing is typed by hand. To change title-page wording (for example the department name), edit the constants at the top of `scripts/build_report.py` and rebuild. Editing the `.docx` directly also works, but a rebuild overwrites it.
